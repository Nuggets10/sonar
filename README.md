# Sonar
Sonar is a lightweight TUI music player written in C++.

## Features
- MP3, WAV and FLAC support
- Autoplay (shuffle, linear, repeat)
- Volume control with software boost
- Pause and play
- Compact terminal user interface

## Installation
Pre-compiled binaries are available in the [Releases](https://github.com/Nuggets10/sonar/releases) tab.

If no binaries compatible with your system are available, please use the following instructions.
This same procedure applies in case you would like to compile the latest source code.

```bash
# Download the source code
git clone "https://github.com/Nuggets10/sonar.git"

# Navigate to the newly created directory
cd sonar

# Start the compilation process. 
make

# Install the executable system-wide
make install

# Start sonar in the current directory
sonar
```
